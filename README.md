# Stock Price Prediction using RNN

## Overview

This project focuses on **Stock Price Prediction using Deep Learning and Recurrent Neural Networks (RNN)**.

The model learns patterns from historical stock price data and uses previous observations to predict future stock prices.

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Recurrent Neural Networks (RNN)

## Project Workflow

1. Load historical stock price data.
2. Explore and analyze the dataset.
3. Select relevant stock price features.
4. Normalize the data.
5. Create sequential training data.
6. Build an RNN-based deep learning model.
7. Train the model using historical data.
8. Evaluate the model performance.
9. Generate predicted stock prices.
10. Visualize actual and predicted prices.

## Model

The project uses a **Recurrent Neural Network (RNN)** to learn patterns from sequential stock price data.

The model uses previous stock price observations as input to predict future price values.
